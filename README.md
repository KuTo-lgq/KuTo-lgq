## 🚀 项目 · Featured

### 📘 [notion-bloom](https://github.com/KuTo-lgq/notion-bloom)

英文 PPT → 汉英双语讲解页，用来备考。面向 Agent 的 Notion 排版与验收 MCP：抽取、检查、写入、排好版，不调用模型 API。  
English slides become a bilingual lecture for exams. An agent-facing Notion beautify and acceptance MCP — extract, check, write, and lay out. No model API.

```bash
npx notion-bloom install
```

### 🔑 [KeyRelay](https://github.com/KuTo-lgq/KeyRelay)

给浏览器 Agent 用的本地加密凭据代理。Bot 只能请求预先授权的登录配方，接口不返回明文密码。  
Local encrypted credential broker for browser agents. Bots run an authorized login recipe; the API never returns plaintext secrets.

### 🧪 [dataset_review_agent](https://github.com/KuTo-lgq/dataset_review_agent)

视觉训练数据集的审计、修复、复核和验收。先自动查出问题，再人工收下能进训练的那一版。  
Audit, fix, and review platform for vision training datasets — from automatic issues to a version a person can accept.
